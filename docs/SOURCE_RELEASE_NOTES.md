This is a development **source prerelease**, not a portable macOS app download.

Extract the source archive and follow README.md or docs/INSTALLATION.md. Local
networking requires an Apple Development certificate and a build made for your
own Mac user. An ad-hoc build cannot register the background service.

The archive includes Tailmulti source, upstream provenance and licenses. The
adjacent `.sha256` file verifies the compressed archive. No signing material,
account state, local logs or app binaries are included.

See CHANGELOG.md and docs/VALIDATION.md for behavior, test evidence and outstanding
live acceptance. This release is not a claim of production readiness.
