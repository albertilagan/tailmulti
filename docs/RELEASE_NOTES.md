This is an early development **prerelease**.

**Install:** download `Tailmulti-<version>-macOS.zip`, unzip it, and move
Tailmulti.app to Applications before opening it. It is signed with Developer ID and
notarized by Apple. Requires an Apple silicon Mac with macOS 26 or later. See
[installation](https://github.com/albertilagan/tailmulti/blob/main/docs/INSTALLATION.md).

The first Mac user who approves the background service becomes its only owner.
Other users on the same Mac cannot control it.

The source archive and each `.sha256` file are also attached. No account state,
signing material or local logs are included.

See CHANGELOG.md and docs/VALIDATION.md for behavior, test evidence and outstanding
live acceptance. This release is not a claim of production readiness.
